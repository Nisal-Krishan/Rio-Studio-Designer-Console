A Real-World, Enterprise-Level Desktop POS & Monitoring Application built exclusively for **Rio Studio** based in Polonnaruwa, Sri Lanka. This software is actively used to monitor designers, track their real-time billing, and analyze overall studio performance.

## 🚀 The "Vibe Coding" Journey
This entire application was developed **without writing manual code**! It was built entirely through an AI-assisted "Vibe Coding" workflow. By engineering master prompts and acting as a Project Manager, the system was brought to life using the most advanced LLMs available.

**🧠 AI Models Used in Development:**
*   **Claude Opus 4.6** (Core Architecture & Logic)
*   **Gemini 3.5 & 3.6** (Data Structuring & Troubleshooting)
*   **Qwen Coder & Qwen 3.8-Max** (UI/UX Refinement & Optimization)

## ⚡ Core Features
*   **Real-Time Cloud Sync:** Powered by Firebase v9 (Firestore). Bills entered by designers instantly update the Admin Dashboard without refreshing.
*   **Role-Based Access (Custom Auth):** 
    *   **Admin (Boss):** Full real-time analytics, Master billing table, Password resetting, and designer management.
    *   **Designers:** Personal dashboard to enter bills and view personal performance.
*   **Pro-Level UI/UX:** Ultra-modern Black & Red "Gaming Studio" theme with a borderless Photoshop-style splash screen.
*   **Over-The-Air (OTA) Updates:** Built-in auto-updater to push future versions directly to studio machines.
*   **Premium Export:** Beautifully formatted PDF/Print generation for accounting.

## 🛠️ Tech Stack
*   **Frontend:** HTML5, CSS3 (Custom Glassmorphism & Animations), Vanilla JavaScript
*   **Backend/Database:** Google Firebase (Firestore Web SDK)
*   **Desktop Wrapper:** Electron.js, Electron-Builder
*   **Development Methodology:** AI Vibe Coding
